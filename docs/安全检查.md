## 一、本机绝对路径 —— 已脱敏

原先有 4 个被跟踪文件含本机盘符路径，现已统一替换为占位符：

| 占位符 | 含义 |
|---|---|
| `<MODEL_DIR>` | 待渲染模型所在目录 |
| `<SOURCE_RIG_DIR>` | 源绑定 / 卡通节点组工程所在目录 |
| `<PIPELINE_DIR>` | 管线输出目录 |
| `<MODEL_ROOT>` | 上述路径的共同上级根目录 |

涉及文件：`docs/需求文档.md`、`reference/一键卡通渲染.py`、`reference/参数面清单.json`、`reference/审计_本次执行.md`。

> 脚本默认常量（`SOURCE_BLEND` / `OUT_DIR`）均以 `os.environ.get(...)` 包裹，改占位符不影响可用性，仍可用环境变量覆盖。

## 二、私有模型 / 贴图 —— 保留（本次未在范围内）
