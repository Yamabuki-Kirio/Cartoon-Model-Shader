## 一、本机绝对路径（⚠️ 命中）

出现盘符路径的文件：

- `docs/需求文档.md` —— 参数数据源路径
- `reference/一键卡通渲染.py` —— 脚本默认常量 `SOURCE_BLEND` / `OUT_DIR`（均被 `os.environ.get(...)` 包裹，可覆盖）
- `reference/一键渲染_通用驱动.py` —— 源工程路径拼接
- `reference/参数面清单.json` —— `subject.input_blend` / `subject.source_rig`
- `reference/审计_本次执行.md` —— 执行对象路径与产出清单

**风险**：暴露本机盘符布局、目录结构与私有素材的存放位置。
**处置**：可将明文替换为占位符（如 `<MODEL_DIR>` / `<SOURCE_RIG>`）；脚本默认常量建议保留环境变量覆盖机制。

## 二、私有模型 / 贴图（⚠️ 命中标识信息）

- 角色名与源绑定工程名散见于 `参数面清单.json`、`审计_本次执行.md`、`一键卡通渲染.py`。
- 源工程专用节点组名（`*_Hair_Reference`）**既是模型标识、也是脚本功能标识**——改名会改变脚本行为，需单独评估或仅在外层文档脱敏。
- 私有 `.blend` 的 SHA-256 指纹出现在 `参数面清单.json` 的 `subject` 段（可用于指纹比对）。
- **未提交任何贴图 / 图片 / 视频实体文件。**
