## 六、写接口与保存功能的安全处置（本轮新增）

| 面 | 处置 |
|---|---|
| 写接口鉴权 | 进程启动生成随机会话令牌；**全部 POST** 强制校验 `X-Toon-Tuner-Token`，缺失/错误一律 401。比较用 `hmac.compare_digest`（常量时间） |
| 令牌落盘 | ❌ 不落盘。Vite 源模板 `web/index.html` 与构建产物 `web/dist/index.html` 都只有占位注释 `<!--TOON_TUNER_TOKEN-->`，令牌由 `GET /` 在响应时注入 |
| 令牌进日志 | ❌ 不进日志。错误信息只说明「缺失 / 不匹配」，不回显令牌；前端诊断面板 dump 前会把 `token` 字段替换为 `<已隐去>` |
| 任意代码 / 命令 | ❌ 不接受。Blender 侧只执行内置模板；字面量一律 `repr()` 量化；新接口 `extra="forbid"`，塞 `code`/`python`/`command` 一律 422 |
| 任意文件路径 | 预设接口**没有任何路径字段**（目录与文件名全由服务端决定，路径穿越在结构上不可能）；`save_as` 只接受「绝对路径 + `.blend` + 父目录存在」，覆盖模式不接受客户端指定目标 |
| 覆盖破坏性 | 默认**另存为**；覆盖（含 `save_as` 落到已存在文件）必须二次确认 + 同目录时间戳备份；**备份失败则拒绝覆盖**；回读校验不通过**绝不保存** |
| 绝对路径展示 | ⚠️ **有意例外**：`SAVE_CONFIRM_REQUIRED` / prepare 响应会展示目标绝对路径与预计备份路径。这是「覆盖前必须让用户看清写到哪」的硬要求；仅出现在该确认载荷与相应的成功响应中，不进日志、不进其它响应 |

自动测试覆盖：令牌在全部写接口上的拒绝矩阵与零副作用、令牌不落静态文件、
篡改 / 复用 / 过期 / 基线失效、备份失败禁止覆盖、回读不一致禁止保存、注入路径与代码的拒绝。

## 六之二、材质图参数面的安全处置（PR #7 新增）

材质图（材质节点树）是**又一条把用户输入送进 Blender 的路**，因此按同一套纪律处置。
完整设计见 [`docs/材质图参数面.md`](材质图参数面.md) §6。

| 面 | 处置 |
|---|---|
| 参数 ID | 客户端只提交服务端生成的 opaque `mg-<hash24>`（`sha256(材质 + 节点结构身份 + 插座 + 字段)[:24]`）。节点名跨材质会重复、且是**用户可改的**，用它当主键既会冲突、又会让「改个名字草稿全废」 |
| 节点路径 | 节点名 / 插座名 / 材质身份**全部**由服务端探测结果拼出（`object_id = 材质名/节点名/插座名`）。请求体里没有它们的字段位置 —— 不是靠过滤，是结构上没有 |
| 字段白名单 | 只允许 `MATERIAL_GRAPH_SOCKET.default_value` 与 `MATERIAL_GRAPH_RAMP.{elements,interpolation}`；`MATERIAL_GRAPH_RAMP.element_count` 在 `READONLY_FIELDS` 里 ⇒ **增删色标在结构上不可能** |
| 属性路径 / 代码 | 注入形态的参数 id 或取值一律只是「不在 schema 内的未知参数」（`PARAM_INVALID`），且**不据此透露任何真实节点名**；字面量一律 `repr()` 量化，绝不字符串拼接 |
| 脚本 / 命令 / 方案 | 材质图**没有**任何接受脚本路径、方案 ID 或命令的入口；接口模型 `extra="forbid"`，塞 `script` / `python` / `command` / `scheme` 一律 422 |
| 共享节点组 | 参数属于被多个材质引用的组时，`confirmed_shared_groups` 未列出即拒绝，并在 `details` 里列出**会一起改到的材质** —— 不让用户在不知道影响谁的情况下改动 |
| 结构指纹 | 材质图结构哈希只含结构（节点增删 / 连线 / 插座结构 / 节点组接口），**不含任何数值**；与基线不符即 `STRUCTURE_CHANGED`，草稿与保存令牌一起作废 |
| 写入前实测 | 写入前用只读探针**实测**一次结构，不只信客户端手里的指纹；已连线插座在 Blender 侧再拒一次 |
| 回滚 | 写前快照、失败即回滚、回读确认；三段（L0 / Cel / 材质图）分开报告，回滚失败明确 `ROLLBACK_FAILED`，不含糊地说「已回滚」 |
| 值域 | 当前可写参数**不下发**值域（已知限制，见设计文档 §7.1）：类型与有限性在服务端把关，值域闸门由执行器单测用显式声明值域的参数钉住 |

自动测试覆盖：注入矩阵（作为参数 id 与作为取值，14 + 8 例）、
`extra="forbid"` 的字段矩阵、共享组未确认拒绝与确认后放行、
写入 / 回读 / 渲染 / 回滚四类失败、改一个材质不影响另一材质、
保存完整材质图草稿、以及加密形态（`mg-<hash>`）的 id 断言。

## 八、MVP-03：预设不携带本机信息（代码级护栏）

预设是「会离开本工具」的东西（用户可能备份、分享），因此**在写入前**做一遍深度扫描，命中即
**拒绝保存**而不是静默清洗 —— 清洗会让用户以为存下了、其实被改过。扫描对象是规范化后的整份预设，
模式分三类：

| 类别 | 拦什么 |
|---|---|
| 路径 | 盘符绝对路径、UNC 路径、`/Users/` 或 `/home/`、`AppData`、`%TEMP%`/`%LOCALAPPDATA%` 等环境变量、`toon-tuner-previews`、`\xxx.png` 这类贴图/模型文件路径 |
| 工程 | `.blend` 引用 |
| 凭据 | 疑似凭据的**字段名**（`token`/`secret`/`password`/`api_key`/`credential`/`auth`）与疑似凭据的**取值**（`ghp_`/`github_pat_`/`sk-`/`token=xxx`） |

配套约束：

- **存储位置不在仓库内**：`%LOCALAPPDATA%\CartoonModelShader\presets`（有测试钉住「默认目录不是仓库的子目录」）。
- **接口不回本机路径**：列表里的 `storage` 只在目录等于默认位置时给占位符写法，其余一律回 `<自定义预设目录>`；
  连相对部分都不给 —— 那部分可能嵌套用户名。
- **测试不污染真实目录**：全部用例注入临时目录，跑完不会在用户目录留下任何文件。

> 单测里出现的 `C:\models\…`、`D:\assets\…`、`ghp_aaa…` 等均为**虚构占位串**，用于验证上述
> 扫描确实会命中；仓库中不含本机真实路径、真实模型路径或任何真实凭据。
